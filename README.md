# ЎзММА - Ижро Интизоми ва Топшириқлар Мониторинги (edo.ijro.uz)

Ушбу платформа Ўзбекистон Миллий медиа ассоциацияси (ЎзММА) бўйича "edo.ijro.uz" тизимидаги Ўзбекистон Республикаси Президенти, Вазирлар Маҳкамаси ҳамда ички ҳужжатлардаги топшириқларнинг кунлик ижроси ва қарздорлигини назорат қилиш учун мўлжалланган.

## Хусусиятлари:
- 👑 Раҳбар назорати (Умумий статистика, қарздорликлар, бўлинмалар рейтинги)
- 👤 Ижрочининг шахсий иш варақаси (Ҳар бир ижрочи кесимида кунлик ҳисобот киритиш ва статус янгилаш)
- 📋 Барча 57 та топшириқ реестри (Филтрлар ва қидирув)
- 📅 Кунлик ўзгаришлар кундалиги
